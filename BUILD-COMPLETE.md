## 🎨 CUSTOMIZATION GUIDE

### Change Colors
Edit `css/style.css` line 9-16:
```css
:root {
    --primary-color: #4F46E5;      /* Your brand color */
    --secondary-color: #06B6D4;    /* Accent color */
    --text-primary: #1F2937;       /* Text color */
    --bg-primary: #FFFFFF;         /* Background */
}
```

### Change Fonts
1. Add Google Fonts link to HTML `<head>`
2. Update `--font-sans` in CSS variables

### Modify Layout
- Container width: Line 99 in style.css
- Spacing: CSS variables (--spacing-sm, md, lg)
- Grid columns: Search for "grid-template-columns"

## 🆘 TROUBLESHOOTING

**Problem:** Images not showing
**Solution:** Check file paths are correct, files exist in images/

**Problem:** Cookie banner not appearing
**Solution:** Clear localStorage, hard refresh browser

**Problem:** Mobile menu not working
**Solution:** Check browser console for errors, verify JavaScript loaded

**Problem:** Form not submitting
**Solution:** Check contact.js loaded, answer CAPTCHA correctly

**Problem:** Styles not loading
**Solution:** Verify style.css path is correct
